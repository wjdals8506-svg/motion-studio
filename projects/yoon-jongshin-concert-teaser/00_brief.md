# 브리프: 윤종신 콘서트 예고

| 항목 | 내용 |
|---|---|
| 주제 | 윤종신 콘서트 예고 |
| 용도 (시청 후 바라는 반응) | 어떤 공연인지 주제나 컨셉이 명확히 드러나는 것 |
| 시청자 | 음악이나 콘서트에 관심 있는 사람 |
| 배포 채널 | 유튜브 |
| 길이 | 30초 |
| 화면 비율 | 16:9 |
| 톤 | 따뜻한, 포근한, 잔잔한 |
| 내레이션 | 없음 |
| 꼭 넣을 것 | 공연명, 날짜, 장소, 키메시지 |
| 절대 피할 것 | 유치한 아동틱하거나, 화려하고 눈부신 비주얼은 지양 |
| 참고 자료 | 없음 |

## 메모
- 길이 30초는 사용자가 "알아서"라고 해서 낸 **제안**이다(컨셉 컷 3~4개 + 공연 정보 + 엔드 화면이 들어가는 길이). 사용자가 "고"로 확정했다. 2단계 컷 설계표는 27~33초 안에서 맞춘다.
- 공연명, 날짜, 장소, 공연 컨셉은 1단계에서 공식 출처(URL)로 확인한 것만 쓴다. 확인되지 않으면 사용자에게 묻는다.
- 실존 인물이므로 본인 사진, AI로 만든 얼굴, 앨범 아트, 공식 포스터를 공개 레포에 넣지 않는다(**제안**, 0단계 시작 때 알림).
- 음악 순서(사용자 요청): 음악 없는 미리보기를 먼저 확인한 뒤 BGM을 만든다. 2단계에서 템포(70~80 BPM 안, **제안**)를 정하고 컷 길이를 마디 단위로 설계한다. BGM은 그 BPM·길이로 생성한 뒤 실제 박자를 분석해 컷 전환과 키 모션을 마디 첫 박·악구 전환에 맞춘다. 설계 문서의 3단계(애니매틱+BGM 동시)는 3단계 계획 때 이 순서로 고친다.
