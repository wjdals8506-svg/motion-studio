# 브리프: 갤럭시 Z 폴드 신제품 광고

| 항목 | 내용 |
|---|---|
| 주제 | 갤럭시 Z 폴드 신제품 광고 |
| 용도 (시청 후 바라는 반응) | 이전 버전 대비 업그레이드된 제품 내외부 스펙 임팩트 |
| 시청자 | 일반 소비자 대중 |
| 배포 채널 | 숏폼 |
| 길이 | 60초 |
| 화면 비율 | 9:16 |
| 톤 | 맞춤형의, 역동적인, 손쉬운 |
| 내레이션 | 없음 |
| 꼭 넣을 것 | 제품명 |
| 절대 피할 것 | 너무 기술적인 수치 |
| 참고 자료 | 없음 |

## 메모
- 사용자 첫 요청: "갤럭시Z폴더 신제품 광고 영상 60초짜리 만들어보자". 제품은 Z 플립이 아니라 Z 폴드로 확인함(2026-11-01).
- 용도(스펙 임팩트)와 시청자(일반 대중)를 함께 보면, 수치를 그대로 나열하기보다 대중이 체감하는 변화(얇아짐, 가벼워짐, 화면, 카메라 등)로 바꿔 보여 줘야 한다(**제안**, 1단계 키메시지에서 정한다).
- 화면 비율 9:16은 숏폼 기본이라 낸 **제안**을 사용자가 "응"으로 확정.
- 톤 원래 답: "맞춤형의, 완벽한, 역동적인, 손쉬운". 3개 기준에 맞춰 "완벽한"을 빼자는 **제안**을 사용자가 "추천대로"로 수락. "완벽한"은 분위기보다 제품 주장에 가까워 1단계 키메시지에서 다시 검토한다.
- 브랜드 자산: 공개 레포라 삼성 로고·공식 사진·영상을 넣지 말자는 **제안**에 사용자가 "상업적 이용은 아니니까 제한 두지 말자"로 답함(2026-11-01). 공식 자산을 쓸 수 있다. 쓴 자산은 출처 URL을 `assets.manifest.json`에 남긴다. 남은 문제: 비상업이어도 공식 사진·영상은 저작권이 삼성에 있고, 원격 렌더를 위해 레포에 올리면 공개 배포가 된다.
- 신제품의 모델명·이전 모델·바뀐 사양은 1단계에서 삼성 공식 출처 URL로 확인한 것만 쓴다.
- 이 브리프는 파일럿(윤종신 예고)의 "스톡 + 글자" 구조를 기준으로 삼지 않는다.
