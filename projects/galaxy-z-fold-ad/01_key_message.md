# 키메시지: 갤럭시 Z 폴드8 울트라 광고

## 확정 문장
> 한 번 펼치면, 다시 접기 싫어진다.

선택 이유: 사용자가 4차(카피라이터 관점) 후보 중 13번을 골랐다(에이전트 추천과 같음). 한 문장에 생각 하나(펼친 쓸모가 커서 되돌아가기 싫다). 시청자 의문("펼치는 게 메리트인지 모르겠다")에 결과로 답한다. 사양(밝아진 화면, 카메라, 배터리, 두께)은 문장이 아니라 컷이 증명한다.

이전 확정안 "더 얇고 밝아진 폴드, 쉽게 펼쳐서 더 많이 한다."(7번 수정안)는 "메시지가 너무 많아. 원메시지가 아니야"로 거절됨. 브리프 용도(이전 대비 업그레이드)와 사용자 방향("펼쳐서 더 많이 할 수 있는 것들"), 시청자 의문("펼치는 게 메리트인지 모르겠다")을 한 문장에 담는다. "얇고"는 펼친 두께 4.2→4.1mm, "밝아진"은 화면 밝기 15% 향상(출처 A).

## 후보
| # | 문장 | 무엇을 강조하나 | 버린 이유 |
|---|---|---|---|
| 1 | 더 얇고, 더 밝고, 더 오래가는 폴드. 펼칠 이유가 많아졌다. | 업그레이드 전체를 "펼칠 이유"로 묶음 (안팎 사양 + 시청자 의문) | |
| 2 | 더 얇아진 폴드, 펼치는 일이 화면을 켜는 일만큼 손쉽다. | 바깥 사양(두께·힌지) → 펼치는 동작의 손쉬움 | |
| 3 | 접으면 폰, 펼치면 지금 하는 일에 꼭 맞는 큰 화면. | 쓰임새(맞춤형) → 펼침의 쓸모 자체 | |
| 4 | 더 단단해진 유리와 힌지, 이제 마음 놓고 펼친다. | 내구성 → 망설임 해소 | |
| 5 | 펼치는 순간, 더 밝은 화면과 카메라가 손 안에서 커진다. | 화면·카메라 밝기 → 펼친 뒤의 체감 | |

### 2차 후보 (사용자 방향 "펼쳐서 더 많이 할 수 있는 것들")
| # | 문장 | 무엇을 강조하나 | 버린 이유 |
|---|---|---|---|
| 6 | 펼치면, 더 많이 할 수 있다. | 방향 그대로, 가장 짧게. 업그레이드는 화면으로만 보여 줌 | 업그레이드 이야기가 빠짐 |
| 7 | 더 얇고 밝아진 폴드, 펼칠수록 할 수 있는 일이 많아진다. | 업그레이드(바깥) + 펼쳐서 더 많이 | **선택 후 수정** → 확정 문장 |
| 8 | 펼쳐서 보고, 찍고, 해낸다. | 할 수 있는 일을 동사로 나열 → 컷 구조로 이어짐 | 사용자가 7번 선택. "해낸다"의 기능 근거 미확인 |
| 9 | 접어서 한 손에, 펼쳐서 더 많이. | 접기·펼치기 대비, 손쉬움 | 사용자가 7번 선택 |

### 3차 후보 (원메시지: 한 문장에 생각 하나)
| # | 문장 | 무엇을 강조하나 | 버린 이유 |
|---|---|---|---|
| 10 | 펼치면, 더 편해진다. | 펼침 = 편함. 시청자 의문(펼치는 게 메리트?)과 친구에게 전할 말(쓰기 편해 보임)에 함께 답함 | |
| 11 | 펼치면, 더 많이 할 수 있다. | 펼침 = 더 많이. 사용자 방향 그대로 | |
| 12 | 펼치는 게 이렇게 쉬웠나. | 펼치는 동작 자체의 손쉬움 | |

10~12번은 보여 주기 전에 사용자가 "카피라이터 페르소나로 다시 제안해봐"라고 해서 4차로 넘어감(설명형 문장이라 광고 카피의 힘이 약함).

### 4차 후보 (카피라이터 관점, 원메시지)
| # | 카피 | 한 가지 생각 | 버린 이유 |

| 14 | 펼쳐 보면 안다. | 의심("메리트인지 모르겠다")에 정면으로 답함 | 사용자가 13번 선택 |
| 15 | 폰을 펼쳤을 뿐인데. | 작은 동작, 큰 변화. 결과는 컷이 말함 | 사용자가 13번 선택. 2단계 첫 2초 훅 후보로 남김 |
| 16 | 펼치는 만큼, 넓어진다. | 화면이 넓어지는 만큼 할 수 있는 일도 넓어짐 | 사용자가 13번 선택. "넓어진다"의 대상이 모호 |

## 메모
- 사용자 결정(2026-11-01): 폴드8(새 가로형 디자인)이 아니라 **폴드8 울트라**의 광고. 삼성이 폴드7과 직접 비교한 항목이 많아 브리프 용도(이전 버전 대비 업그레이드)에 맞는다는 추천을 "1"로 수락.
- 쓰지 않는 것(공식 출처로 확인 못 함): 무게, 접은 두께, 충전 속도(W), 칩셋 향상 %, 출시일, 가격, 색상. 검색 결과의 2차 보도는 수치가 서로 달랐다(배터리 5,000 vs 4,854mAh, NPU 21% vs 39%). 필요하면 삼성 뉴스룸 원문으로 다시 확인한다(뉴스룸 페이지는 이번에 시간 초과로 열리지 않음).
- 질문 1(리서치 중 이미 알거나 틀린 것) 사용자 답: "없음".
- 질문 2(시청자가 잘못 알거나 모르는 것) 사용자 답: "펼치는 게 메리트인지 모르겠다". 후보는 이 의문에 답하는 쪽으로 잡았다.
- 질문 3 1차 답: 1~5번 중 고르지 않고 "펼쳐서 더 많이 할 수 있는 것들 이런 방향이 좋을 듯" → 2차 후보 6~9번.
- 질문 3 답: "7".
- 질문 4(친구에게 한 줄로 전한다면) 사용자 답: "생각보다 쓰기 편해보이는 듯?" → 확정 문장과 표현이 다름. 시청자가 가져갈 느낌은 "더 많이"보다 "쓰기 편함"(톤 '손쉬운').
- 질문 4 후속: 7번 유지 vs 손쉬움을 넣어 수정 중 "2"(수정) 선택. 확정 문장 "더 얇고 밝아진 폴드, 쉽게 펼쳐서 더 많이 한다."
- 위 확정 문장을 사용자가 거절: "메시지가 너무 많아. 원메시지가 아니야". 한 가지 생각만 담는 3차 후보를 낸다. 얇음·밝음 같은 사양은 문장에서 빼고 컷의 근거로 보낸다.
- 질문 3 최종 답: "13".
- 남은 문제: 카피에 브리프 용도("이전 버전 대비 업그레이드")가 드러나지 않는다. 2단계 컷이 폴드7 대비 업그레이드(밝은 화면, 카메라, 배터리 등)를 보여 줘야 한다.
- 질문 4 답: "스펙으로 표현하지 말고, 내가 준 레퍼럴 메시지로 연결 될 수 있게 표현하자". 레퍼럴 메시지 = 시청자가 친구에게 전할 한 줄 "생각보다 쓰기 편해보이는 듯?". → 업그레이드는 숫자·폴드7 비교로 보여 주지 않는다. 사양은 숨은 근거로만 두고, 화면에는 "생각보다 편한 순간"(체감 장면)으로 보여 준다. 연결 구조(**제안**): 생각보다 편한 순간들 → 카피 "한 번 펼치면, 다시 접기 싫어진다." → 시청자 한 줄 "생각보다 쓰기 편해 보이던데".
- 사용자 보충: "변화는 당연히 보이긴 해야지. 대신 스펙 변화 자체를 중심으로 구성하진 말라는거야". → 구성의 뼈대는 "생각보다 편한 순간들"(쓰는 장면)이고, 각 순간 안에서 업그레이드가 눈에 보여야 한다(예: 짧은 쉬운 말 자막 "더 밝게", "더 오래"처럼 숫자 없이). 사양 비교표식 나열 구성은 하지 않는다.
- 2단계 제안: "얇음"은 크게 내세우지 않고 펼치는 동작의 가벼운 손맛으로 보여 준다.
- 남은 문제: "더 얇고"의 근거는 폴드7 대비 0.1mm(4.2→4.1mm)라 체감이 작다.
- 브리프의 "너무 기술적인 수치 제외"에 따라 영상에는 mAh·니트·MP 같은 단위를 그대로 쓰지 않고 체감 표현으로 바꾼다(**제안**).
