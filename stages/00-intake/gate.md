# 0단계 게이트

## 승인 요청 전 확인
- [ ] 브리프 표의 모든 칸이 채워졌다. 비운 칸은 "해당 없음"과 이유를 적었다.
- [ ] 길이가 숫자(초)로, 비율이 하나로 정해졌다.
- [ ] 톤이 형용사 3개 이하다.
- [ ] 사용자의 말을 바꾸지 않고 옮겼다. 제안한 값은 메모에 "제안"이라고 표시했다.

## 사용자에게 보여줄 것
한 페이지 브리프(`00_brief.md`) 전체.

## 승인 후
`status: approved`, `approved_at: YYYY-MM-DDTHH:MM` → `taste/verdicts.md` 기록 → 커밋·푸시.
