# 2단계 게이트

## 승인 요청 전 확인
- [ ] 스토리라인 3안의 종류가 서로 다르다.
- [ ] 모든 컷에 "시청자가 믿게 될 것"이 하나씩 있고, 이어 읽으면 키메시지로 끝난다.
- [ ] 모든 컷의 `연결(서사)`와 `연결(디자인)`이 채워졌다. 마지막 컷은 엔드 홀드를 적는다.
- [ ] 키 모션은 영상 전체에서 소수(대략 컷 수의 절반 이하)만 표시했다. 효과음은 키 모션에만 붙는다.
- [ ] 컷 길이 합이 브리프 길이 ±10% 안이다.
- [ ] `director` 스킬의 never-ship 목록에 걸리는 컷이 없다(카운터 라벨, 덱 레이아웃, 슬로건 카피 등).
- [ ] 컷 길이의 최장/최단이 2배 이상이고, 2~4초마다 새로운 것이 나오며, 같은 배치·진입이 6초를 넘지 않는다(director laws.md "새로움과 길이 대비").
- [ ] 컷마다 히어로가 화면의 40% 이상이고, 큰 글자 컷이 모두 정중앙은 아니다(composition.md).
- [ ] 큰 변화(키 모션·장면 전환)는 음원에서 측정한 프레이즈 경계에 있다. 측정 전이면 "측정 필요"로 적었다.
- [ ] 바탕 전환을 불투명도·색 페이드로 계획한 이음새가 없다(connection.md). 글자를 가려도 각 컷에 그림(표면)이 남는다.
- [ ] 내레이션이 있으면 원고의 숫자·영문에 한글 읽기를 병기했다.
- [ ] 점수를 매기거나 "좋다"고 스스로 인증하지 않았다.

## 사용자에게 보여줄 것
스토리라인 3안 → 선택 → 컷 설계표 → (있으면) 원고.

## 승인 후
`status: approved`, `approved_at: YYYY-MM-DDTHH:MM` → `taste/verdicts.md` 기록 → 커밋·푸시. 다음은 3단계(애니매틱과 BGM)이며 별도 구축 계획이 필요하다.
