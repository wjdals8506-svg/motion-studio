# 1단계 게이트

## 승인 요청 전 확인
- [ ] 후보가 3~5개이고 서로 강조점이 다르다(같은 말의 바꿔 쓰기가 아니다).
- [ ] 각 후보가 한 문장이다.
- [ ] 영상에 들어갈 수치·사실은 모두 출처 URL과 확인 날짜가 있다. 출처를 못 찾은 것은 쓰지 않는다.
- [ ] 확정 문장이 브리프의 용도·시청자와 맞는다.

## 사용자에게 보여줄 것
리서치 요약 → 후보 표 → 확정 문장(사용자가 고른 것).

## 승인 후
`status: approved`, `approved_at: YYYY-MM-DDTHH:MM` → `taste/verdicts.md`에 고른 문장과 버린 후보의 이유 기록 → 커밋·푸시.
