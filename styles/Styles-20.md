# 모션그래픽 디자인 레퍼런스: 스타일·모션 20선
 
> 출처: AEWON STUDIO(@aewonstudio) SNS 무료자료 "클로드로 만드는 AI 모션 효과 20가지 + 효과별 프롬프트"
> 용도: 모션그래픽 제작 시스템의 디자인 레퍼런스 자료. 스타일 선택, 모션 어휘, 팔레트, 구현 기술 참고용.
> 구성: 1) 사용 원칙 2) 20선 요약표 3) 분류별 색인 4) 스타일별 상세 5) 원문 프롬프트(구현 예시)
 
## 1. 이 문서의 사용 원칙 (Claude용)
 
- 이 문서는 "만들어 달라는 명령 모음"이 아니라 "스타일과 모션을 고를 때 참조하는 자료"다. 사용자가 번호를 말해도 자동으로 제작을 시작하지 않는다.
- 제작 요청이 오면 먼저 요청의 목적과 분위기에 맞는 스타일 후보를 4절에서 1~3개 고르고, 근거(색, 모션, 질감)를 들어 제안한다.
- 스타일을 결정한 뒤에는 해당 항목의 "모션 동작", "색·재질", "배경"을 설계 기준으로 쓰고, 5절 원문 프롬프트는 구현 방식의 예시로 참고한다.
- 여러 스타일을 섞을 때는 한 화면에 모션 어휘를 1~2개로 제한한다. 원문 20선은 모두 "하나의 대상 + 하나의 반복 모션"으로 구성돼 있다.
- 원문 20선의 공통 조건: 정사각형 카드 안에서, 끊김 없이 반복되며, 바로 미리 볼 수 있는 HTML 한 개 (5절 참고).

## 4. 스타일별 상세
 
### 1. Liquid Motion 리퀴드 모션
 
- 한 줄 요약: 일렁이며 모양이 바뀌는 액체 덩어리
- 구현 기술(원문 지정): 레이마칭 셰이더(메타볼)
- 색·재질: 무지갯빛 반사, 매끈한 크롬
- 모션 동작: 공 여러 개가 붙었다 떨어짐, 천천히 일렁이며 형태가 계속 변함
- 배경: 짙은 보라
- 키워드: 유기적 변형, 액체, 크롬
### 2. Holographic 홀로그래픽
 
- 한 줄 요약: 각도 따라 흐르는 무지개 홀로그램
- 구현 기술(원문 지정): three.js + 블룸
- 색·재질: 무지갯빛, 대각선 줄무늬, 반짝이는 작은 점
- 모션 동작: 카드가 좌우로 기울며 회전, 기울 때마다 무지개색이 표면 위로 흐름, 빛이 은은하게 번짐
- 배경: 남색
- 키워드: 각도 반응 색 변화, 광택, 글로우
### 3. Claymorphism 클레이모피즘
 
- 한 줄 요약: 통통 튀는 말랑한 점토 도형
- 구현 기술(원문 지정): three.js
- 색·재질: 무광 파스텔, 둥근 모서리, 바닥의 부드러운 그림자
- 모션 동작: 도형 3개(재생 버튼, 토글 스위치, 도넛)가 시간차로 하나씩 통통 튀어 오름
- 배경: 연한 라벤더
- 키워드: 말랑함, 시간차(스태거), UI 아이콘 소재
### 4. Halftone 하프톤
 
- 한 줄 요약: 인쇄물 망점으로 그린 입체
- 구현 기술(원문 지정): three.js + 후처리 셰이더
- 색·재질: 주황 바탕 + 검정 망점, 레트로 인쇄물. 밝은 곳은 작은 점, 어두운 곳은 큰 점
- 모션 동작: 도넛이 천천히 회전, 화면 전체가 하프톤 망점으로 변환
- 배경: 주황
- 키워드: 인쇄 질감, 2색 제한, 후처리
### 5. Isometric 아이소메트릭
 
- 한 줄 요약: 비스듬히 내려다본 작은 3D 도시
- 구현 기술(원문 지정): three.js (아이소메트릭 시점)
- 색·재질: 파스텔 핑크·보라·노랑, 바닥은 초록 잔디와 도로
- 모션 동작: 건물이 아래에서 하나씩 솟아오름, 창문 불빛이 군데군데 깜빡임
- 배경: 초록 잔디·도로 바닥
- 키워드: 순차 등장, 비스듬한 시점, 미니어처
### 6. Kinetic Typography 키네틱 타이포그래피
 
- 한 줄 요약: 리듬 있게 들어오는 굵은 글자
- 구현 기술(원문 지정): GSAP
- 색·재질: 형광 라임 띠, 외곽선만 있는 큰 글자
- 모션 동작: 세 단어가 줄마다 다른 타이밍으로 튀어 들어옴, 라임 띠가 가운데 줄을 쓸고 지나감, 뒤의 외곽선 글자가 옆으로 계속 흐름
- 배경: 짙은 남색
- 키워드: 타이포 리듬, 줄별 타이밍 차, 스윕, 흐르는 배경 글자
### 7. Y2K Chrome Y2K 크롬
 
- 한 줄 요약: 거울처럼 반짝이는 크롬 오브젝트
- 구현 기술(원문 지정): three.js + 환경맵
- 색·재질: 거울 반사 크롬, 얇은 고리
- 모션 동작: 크롬 별 오브젝트가 고리와 함께 천천히 회전, 금속 반사
- 배경: 밝은 하늘색과 라벤더 (Y2K)
- 키워드: 금속 반사, 2000년대 감성
### 8. Paper Cutout 페이퍼 컷아웃
 
- 한 줄 요약: 층마다 다르게 움직이는 종이 풍경
- 구현 기술(원문 지정): 레이어 + 패럴랙스 (기술 지정 없음)
- 색·재질: 종이 오려 겹친 질감, 층마다 아래쪽 종이 그림자
- 모션 동작: 층마다 다른 속도로 좌우로 흔들림(패럴랙스)
- 배경: 맨 뒤 해·구름, 산 세 겹, 맨 앞 나무
- 키워드: 깊이감 레이어, 속도 차, 그림자로 층 분리
### 9. Infinite Zoom 인피니트 줌
 
- 한 줄 요약: 끝없이 빨려 들어가는 터널
- 구현 기술(원문 지정): 셰이더
- 색·재질: 청록·남색·분홍 띠, 중앙은 밝게 발광
- 모션 동작: 둥근 사각형 고리가 겹겹이 반복, 계속 확대되며 살짝 회전, 이음새 없는 무한 반복
- 배경: 터널 중심 발광
- 키워드: 심리스 루프, 반복 구조, 확대
### 10. Vaporwave 베이퍼웨이브
 
- 한 줄 요약: 네온 격자 바닥과 줄무늬 노을
- 구현 기술(원문 지정): (기술 지정 없음)

- 모션 동작: 격자 바닥이 끊김 없이 앞으로 계속 다가옴
- 배경: 보라→분홍 그라데이션 하늘
- 키워드: 네온, 심리스 이동, 레트로 퓨처

## 5. 원문 프롬프트 (구현 예시)
 
> 공통 기본 문장 (원문에서 각 프롬프트 앞에 붙이라고 안내한 문장):
 
```text
HTML 파일 한 개로 만들어줘. 화면 가운데 정사각형 카드 안에서 끊김 없이 반복해서 움직이게 하고, 바로 미리 볼 수 있게 해줘.
```
 
### 1. Liquid Motion 리퀴드 모션
 
```text
레이마칭 셰이더로 공 여러 개가 서로 붙었다 떨어지는 액체 덩어리(메타볼)를 만들어줘.
표면은 무지갯빛으로 반사되는 매끈한 크롬 느낌, 배경은 짙은 보라색.
덩어리는 천천히 일렁이면서 모양이 계속 바뀌게 해줘.
```
 
### 2. Holographic 홀로그래픽
 
```text
three.js로 홀로그램 카드를 만들어줘.
카드가 좌우로 살짝 기울어지며 돌고, 기울 때마다 무지개색이 표면 위로 흐르게 해줘.
대각선 줄무늬와 반짝이는 작은 점을 얹고, 빛이 은은하게 번지게(블룸) 해줘. 배경은 남색.
```
 
### 3. Claymorphism 클레이모피즘
 
```text
three.js로 점토처럼 말랑한 3D 도형 세 개(재생 버튼, 토글 스위치, 도넛)를 만들어줘.
무광 파스텔 색, 둥근 모서리, 바닥에 부드러운 그림자.
도형이 하나씩 시간차를 두고 통통 튀어 오르게 하고, 배경은 연한 라벤더.
```
 
### 4. Halftone 하프톤
 
```text
three.js로 천천히 도는 도넛을 그리고, 화면 전체를 하프톤 망점으로 바꾸는 후처리 셰이더를 씌워줘.
밝은 곳은 점이 작고 어두운 곳은 점이 크게, 주황 바탕에 검정 점으로 레트로 인쇄물 느낌을 내줘.
```
 
### 5. Isometric 아이소메트릭
 
```text
three.js로 위에서 비스듬히 내려다본(아이소메트릭) 작은 도시 블록을 만들어줘.
건물이 아래에서 하나씩 솟아오르고, 창문 불빛이 군데군데 깜빡이게 해줘.
색은 파스텔 핑크·보라·노랑, 바닥은 초록 잔디와 도로.
```

```text

세 단어가 줄마다 다른 타이밍으로 튀어 들어오고, 형광 라임색 띠가 가운데 줄을 쓸고 지나가게 해줘.
뒤에는 외곽선만 있는 큰 글자가 옆으로 계속 흐르게 하고, 배경은 짙은 남색.
```

