# 내보내지 않는 것 (never-ship)

어떤 요소를 넣을지 망설일 때, 컷 설계표·애니매틱·키 컷을 점검할 때, 리뷰에서 프레임을 하나씩 볼 때 읽는다. 여기 걸리는 요소는 지운다. 정당화하지 않는다.

## motionmaxxing never-ship 12항목
- 화면 크롬·HUD(구석의 브랜드·영상 이름, 자간 넓힌 대문자 라벨, "02 / 말하기" 같은 카운터, 타임코드, BPM·FPS·해상도 글자, 진행 막대, 모서리 괄호, 샷 위의 장면 라벨) 금지 → 프레임에는 주장, 제품(대상), 로고 한 번만 둔다. 챕터는 배경 변화와 운반 물체로 알린다. (출처: mm/SKILL.md never-ship 1, mm/references/slop.md N1·N2)
- 덱 레이아웃(왼쪽 정렬 헤드라인 블록을 붙잡아 두기, 헤드라인 위 키커, 제목 다음 내용, 헤더·본문·푸터, "왼쪽 헤드라인 + 오른쪽 기기") 금지 → 가운데 한 줄을 말의 속도로, 또는 먼 쪽 절반이 물체가 되는 분할 문장. (출처: mm/SKILL.md never-ship 2, mm/references/slop.md N3)
- 흔한 웹 컴포넌트 UI(상태 점 + "라벨 · 값" 둥근 카드, "Good morning" 카드, 동그라미 세 개 툴바, 회색 아연색, 스켈레톤 막대, 실제 자료가 있는데 지어낸 이름·숫자) 금지 → 실제 화면을 카메라로 확대한 조각, 실제 아이콘·문장·시간. (출처: mm/SKILL.md never-ship 3, mm/references/slop.md N5)
- 이름·주제의 첫 연상(별 같은 이름에 별, "출시"에 로켓, 보안에 방패) 금지 → 첫 아이디어는 적고 치워 두고, 다른 종류의 아이디어 둘을 더 낸다. (출처: mm/SKILL.md never-ship 4, mm/references/idea.md 3절)
- 지어낸 통계와 증거, 스탯 벽, 스탯 슬라이드(가운데 큰 숫자 + 작은 라벨), 화면 위 면책 문구 금지 → 숫자는 실제이고 출처 URL이 있을 때만, 그 숫자를 일으키는 원인과 함께 물리적 비트 안에서. 아니면 숫자를 빼고 그 대상을 보여준다. (출처: mm/SKILL.md never-ship 5, mm/references/slop.md N7, CLAUDE.md 11)
- 슬로건 카피(한 단어 문장 세 개 "더 빠르게. 더 똑똑하게. 당신의 것.", "단순한 X가 아니다. Y다.", "잠금 해제", "X를 만나보세요", "~의 미래") 금지 → 말하듯 쓴 문장 하나를 쓰고 절반을 자른다. 다른 영상에 그대로 붙여도 되는 줄이면 다시 쓴다. (출처: mm/SKILL.md never-ship 6, mm/references/type.md 0.3절)
- 하우스 스타일을 기본값으로(화면 밖으로 잘린 거대한 단어, 글자 안의 질감, 비트 사이 색 범람·원형 와이프, 로고가 되는 점, 모티프로 만든 로크업, 변신 사슬, 캐럿으로 타이핑되는 헤드라인) 금지 → 이 주제의 아이디어가 바로 그것일 때만 쓰고, 그 이유를 한 문장으로 적는다. 헤드라인 타이핑은 이유가 있어도 금지. (출처: mm/SKILL.md never-ship 7, mm/references/type.md 0.4절)
- 장면마다 평평한 색면 배경, 빈 바탕 위 작은 카드(0.3W 물체를 1초 읽기) 금지 → 막마다 표면(캡처 플레이트, 재질, 방향 있는 빛)을 만든다. 평평한 색은 1초 미만의 범람·다이브에만. (출처: mm/SKILL.md never-ship 8, mm/references/world.md 3절)
- 고정된 물체(알약·독을 세 샷 이상 같은 좌표에) 금지 → 운반 물체는 이음새마다 움직이거나 크기·역할이 바뀐다. (출처: mm/SKILL.md never-ship 9, mm/references/slop.md N8)
- 웹 푸터 엔딩(로고 + 태그라인 + 버튼 + URL), 1.4초 넘게 붙잡는 엔드 카드 금지 → 원인으로 도착한 마크 하나 또는 음성에 실린 이름, 결정된 홀드 0.6~1.4초. (출처: mm/SKILL.md never-ship 10, mm/references/close.md R2.0)
- 자기 인증(NOTE.md 없음, 스크립트 수치 없이 게이트 통과 주장, "정당화된" 실패) 금지 → NOTE.md와 REVIEW.md에 측정한 수치를 인용하고 남은 문제를 그대로 적는다. 점수를 매기지 않는다. (출처: mm/SKILL.md never-ship 11, hf/review.md 3절)
- 보지 않은 영상 금지 → 스냅샷 시트의 모든 프레임을 처음 보는 사람처럼 한 문장으로 묘사한 뒤 판단한다. 15초짜리 검은 렌더가 "검증 완료"로 인증된 적이 있다. (출처: mm/SKILL.md never-ship 12, hf/review.md 2절)
- 페이지 크롬(라벨, 카운터, 타임코드, 헤더, 푸터, 키커)에는 "되는 조건"이 없다. 다른 항목과 달리 예외를 찾지 않는다. (출처: mm/references/slop.md Part 1b)

## AI 기본값 vs 프로 판단 (핵심 10개)
- 모든 것에 같은 이즈아웃 하나 금지 → 역할마다 곡선: 진입은 softLand·snapSettle(처음 4~5f에 이동 60~72% 후 0.4~0.6초 꼬리), 퇴장은 accelExit 6~13f, 카운터는 프레임 단위 스텝, 드리프트는 cruise. (출처: mm/references/slop.md M1)
- 장면 사이 불투명도 크로스페이드, 카드·자막 사이 디졸브 금지 → 움직임 중의 하드 컷과 맞춘 물체. 페이드는 Part 1b 조건(차분한 브랜드, 의미 있는 디졸브, 단일 객체)일 때만. (출처: mm/references/slop.md X1)
- 다음 장면이 정지 상태에서 시작 금지 → 다음 장면의 첫 프레임은 이미 움직이고(1프레임에 105~280px, 블러, 줌 중간) 이전 벡터를 따라간다. (출처: mm/references/slop.md X3)
- 마지막 프레임과 다음 첫 프레임이 무관함 금지 → 물체·자세·문자열·배경·캐럿 하나를 약 0.03 이내 같은 위치로 넘긴다. (출처: mm/references/slop.md X4)
- 붙잡힌 프레임이 얼어 있음, 붙잡았다 바꾸기(줄마다 1.2초 이상 붙잡았다 교체) 금지 → 붙잡은 프레임마다 살아 있는 것 하나. 진짜 홀드는 보상 뒤 0.5~1.0초, 보상 전 이유 있는 숨 0.6~1.5초. (출처: mm/references/slop.md M5)
- 헤드라인 단어가 불투명도 0 → 1로 페이드 인 금지 → 단어가 한 프레임에 통째로 착지하거나, 0.03~0.24H 오프셋에서 3~6px 블러를 4~8f에 걷으며 들어온다. (출처: mm/references/slop.md T1)
- 로고가 0에서 커지거나 페이드 인 금지 → 크고 흐리게 들어와 줄어든다(초과분이 2f마다 절반). 또는 부품으로 조립. (출처: mm/references/slop.md M10)
- 기능 투어(카드 + 캡션 × N, 같은 길이, 같은 y의 캡션) 금지 → 증거 하나, 프레임당 물체 하나, 길이가 다른 비트. (출처: mm/references/slop.md N6)
- 같은 길이의 비트 금지 → 비트는 짧아지다가 마지막이 머문다(예: 1.3 / 1.07 / 0.70 / 0.43초 다음 0.6초 제목). (출처: mm/references/slop.md Tm1)
- 여러 물체에 액센트 색 금지 → 색 하나에 의미 하나("작동 중", "도착"), 신호색은 최대 하나(완료 = 초록), 한 물체에 둘을 함께 쓰지 않는다. (출처: mm/references/slop.md K1)

## 모든 요소에 같은 이징·같은 길이 금지
- 모든 요소에 같은 `power2.out` 0.5초 같은 단일 이징·단일 길이 금지 → 역할로 고른다. 도착은 긴 꼬리, 카메라 이동과 색 변화는 양쪽 이징, 줌 스루와 퇴장은 가속, 선형은 회전·진행률·일정 속도만. 값은 `tokens/motion.json`의 `measured_eases`에서 고른다. (출처: hf/motion.md, mm/references/director.md 슬롭 표)
- 같은 비트의 여러 진입이 한 곡선을 공유 금지 → 진입마다 오프셋 크기와 꼬리를 다르게 해서 따로 움직이는 몸체로 읽히게 한다. (출처: mm/references/motion.md R3.3)
- 균일한 0.1초 stagger, 모든 글자에 같은 작은 슬라이드 인(24px, 4~6px 블러, 40~80ms) 금지 → 불규칙한 간격(3,2,2,2,2,2), 역할별 곡선, 0.03~0.24H 오프셋. (출처: mm/references/slop.md M4)
- 모든 장면이 같은 방식으로 들어옴, 모든 요소가 페이드 + 위로 슬라이드 금지 → 영화 안에서 제목 진입 방식을 바꾼다(단어별 블러 걷힘, 회색에서 잉크로, 줄 전체 블러 인 등). (출처: hf/motion.md)
- 제목·UI에 숨쉬기·떠다니기·맥박 루프, 착지 후에도 계속 미끄러지거나 커지는 제목, 장면 끝의 느린 크리프 스케일, UI 바운스, 클릭 링 금지 → 착지하면 멈추고, 움직임은 다음 요소·카메라·배경으로 옮긴다. 누름은 찌그러짐과 1f 뒤 대상의 반응으로. (출처: hf/motion.md, mm/references/slop.md U5)

## 위 목록 밖의 "티"가 맞는 조건
위 never-ship 12항목에는 조건이 없다. 아래는 AI가 남용하지만 조건이 맞으면 쓰는 것들이다. 조건을 한 문장으로 적지 못하면 쓰지 않는다.
- 캐럿이 있는 타이핑 금지 → 대상이 곧 입력하는 도구이고 그 입력창 안에서 타이핑할 때, 또는 캐럿이 다른 무언가(구분선, 글자)가 될 때만. 헤드라인에는 조건이 없다. (출처: mm/references/slop.md Part 1b)
- 가운데 정지 엔드 카드 금지 → 꾸준한 움직임 뒤에 오고, 오프닝을 메아리치며, 로고가 원인으로 도착했고, 0.6~1.4초일 때만. (출처: mm/references/slop.md Part 1b)
- 부드러운 그라데이션·글로우 구체 금지 → 그 브랜드·주제 고유의 재질이거나, 역할 있는 물체이거나, 분위기에 따라 변하는 광원 하나일 때만. 모든 장면 아래 벽지로는 안 된다. (출처: mm/references/slop.md Part 1b)
- 대부분 빈 프레임과 작은 글자 금지 → 대상이 정확히 하나이고, 눈을 이끄는 것(커서, 음성)이 있고, 빈 것이 역할(보상 전 숨, 매치 컷 뒤 고립)을 하고, 약 1.5초 미만이며 폰 크기가 아닐 때만. (출처: mm/references/slop.md Part 1b)
- 숫자 카운트업 금지 → 숫자가 실제 핵심이고 크기가 요점이며 그것을 일으키는 조작에 묶여 있을 때만. 증거 질감인 숫자는 처음부터 완성된 채로 나온다. (출처: mm/references/slop.md Part 1b, mm/references/type.md R8.5)
- 화면 밖으로 잘린 거대한 단어 금지 → 아이디어가 그 단어를 거대하게 원하고, 원인(카메라 팬, 표면)과 함께 한 번 도착하고, 스케일을 다시 쓰지 않을 때만. (출처: mm/references/slop.md Part 1b)
- 로고가 되는 점, 모티프 로크업, 변신 사슬 금지 → 그것이 정확히 이 주제의 아이디어이고 고리마다 참일 때만. 아니면 로고는 원인으로 도착한다. (출처: mm/references/slop.md Part 1b)
- 페이드 투 블랙, 조용한 엔딩 금지 → 차분한 주제이고 영상이 내내 숨을 쉬었을 때만(사람이 만든 51편 중 약 22편이 조용히 끝난다). (출처: mm/references/judgment.md 8절)
- 슬라이드 문법(가운데 한 줄, 평평한 바탕, 컷) 금지 → 말의 속도에 맞추고, 글자 위치가 바뀌지 않고, 두 번째 시각 목소리(커서, 물체)가 위트를 더할 때만. 라벨·카운터·보조 줄·키커는 그때도 금지. (출처: mm/references/slop.md Part 1b)
- 슬라이드 테스트: 시트의 글자를 손으로 가린다. 프레임의 절반 넘게 "평평한 색 위 카드나 덩어리"면 덱이다 → 글자가 아니라 그림을 고친다. (출처: mm/references/slop.md never-ship 슬라이드 테스트)
